# zachbuttram.com

Personal site, built with [Astro](https://astro.build) and Tailwind CSS and deployed to Cloudflare Pages.

```sh
npm install
npm run dev     # local dev server
npm run build   # type-check and build to ./public
```

Static assets live in `static/` and the build outputs to `public/` (a holdover from the Gatsby days that keeps the Cloudflare Pages settings unchanged).
